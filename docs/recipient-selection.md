# 기부자 수혜기관 선택 연결

## 확인 경로

1. `/donor/mypage/items`에서 아동 도서를 선택합니다.
2. 물품 상세의 `추천 기관 보기`를 누릅니다.
3. 추천 기관의 상세 정보와 추천 이유를 확인합니다.
4. `이 기관 선택하기`를 누르고 확인 팝업에서 선택을 확정합니다.
5. 추천 목록에서 선택한 기관을 확인합니다. 다른 기관을 선택하면 확인 후 기존 선택을 교체합니다.

직접 확인: `/donor/recommendations/books-12`

## A/B 연결 경계

- A: 추천 목록, 기관 상세, 확인 팝업, 최종 선택 데이터 구성.
- B: 서버 매칭 생성, 권한·잔여 수량 재검증, 채팅 및 거래 진행.
- `RecipientSelection`은 `donationId`, `organizationId`, `needId`, `quantity`를 전달합니다.
- 현재 `useDonorStore`는 물품·프로필·물품별 선택을 하나의 Zustand 상태와 sessionStorage(`issum-donor-demo-v1`)에 저장합니다. 새로고침에는 유지되며 계정이나 서버에는 저장되지 않습니다.
- 등록한 실제 로컬 물품의 품목과 남은 수량으로 추천 화면을 구성합니다. 물품 수정·삭제 시 해당 선택을 제거하며 완료·만료·잔량 없는 물품은 선택할 수 없습니다.
- 샘플 후보는 중 이상 상태를 요청하므로 하 상태 물품에는 빈 추천을 표시합니다. 이 규칙은 실제 AI 평가 기준이 아닙니다.
- 서버 연결 전 데모입니다. `sample-`로 시작하는 필요 물품 ID는 실제 API에 전송하면 안 됩니다. 추천 응답의 실제 ID와 수량으로 교체해야 합니다.
- 현재 확인 버튼은 로컬 선택만 저장합니다. 매칭 성공·예약·채팅방 생성으로 취급하지 않습니다.
- API 연결 시 서버 성공 응답 이후 상태를 갱신하고 실패·수량 변경·이미 매칭된 경우의 재선택을 처리해야 합니다.
- 예시 기관 주소·소개는 샘플이며 실제 연락처가 없어 미등록으로 표시합니다. 실제 AI 분석은 실행하지 않습니다.
