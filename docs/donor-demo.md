# 기부자 프론트 데모 확인

## 실행

Node.js 22 이상에서 `pnpm install`, `pnpm dev`를 실행하고 터미널에 표시된 주소의 `/donor/home`으로 접속합니다.

화면은 현재 브라우저 탭의 세션 저장소를 사용합니다. 새로고침에는 유지되지만 다른 기기·계정과 동기화하지 않습니다. 탭 종료 후 브라우저의 세션 복원 설정에 따라 복원될 수 있습니다. 서버로 물품이나 사진을 보내지 않습니다.

## 구현한 동작

- 등록: 카테고리별 고정 품목, 1~9999 정수 수량, 수령 지역·시작일·종료일, 상태, 선택 설명, 사진 1~3장.
- 사진: JPG·PNG·WebP 장당 1MB 제한, 실제 이미지 판독, 미리보기와 삭제. 읽는 중 중복 등록을 막습니다.
- 입력 검증: 필수값·날짜·수량 검사, 단계 이동 시 값 유지, 이탈 확인, 새로고침 시 미저장 경고.
- 저장: 성공 후 상세·추천으로 이동. 중복 제출 방지. 저장 용량 초과·저장 차단 시 오류를 표시하고 입력 및 기존 데이터를 유지합니다.
- 수정·삭제: 해당 ID의 실제 로컬 정보를 사용. 예약 수량이 있거나 완료된 물품은 화면과 저장 로직 양쪽에서 차단합니다.
- 홈·마이페이지·목록·내역: 같은 저장소로 통계와 프로필을 계산. 완료 내역과 상세의 수령 기관·완료일이 일치합니다.
- 탐색: 품목·기관 검색, 카테고리·지역·상태 복합 필터, URL 조건 유지, 빈 결과·잘못된 상세 주소 안내. 필요 품목에서 등록 화면으로 품목을 전달합니다.
- 추천: 새 물품도 목록·기관 상세·선택·변경 가능. 물품 변경 시 이전 선택 제거. 선택한 기관과 최신 수량을 저장합니다.
- 요청 목록: 샘플 요청의 필터 및 연결된 물품 조회. 삭제된 물품의 요청은 목록에서 제외합니다. 실제 요청 전송은 하지 않습니다.
- 프로필: 이름·생년월일·이메일·전화·주소 검증과 저장, 홈 및 마이페이지 반영, 미저장 이탈 확인.
- 공통 팝업: 키보드 포커스 이동 제한·복원, Escape 취소, 긴 내용 스크롤.

## 빠른 확인 순서

1. 홈 → 등록: 필수 입력과 사진을 넣고 등록합니다.
2. 내 물품 보기 → 수정: 수량을 바꿔 저장하고 목록·홈 통계를 확인합니다.
3. 추천 기관 보기 → 상세 → 기관 선택 확인: 새로고침해 선택 유지 여부를 확인합니다.
4. 물품을 다시 수정하면 기존 선택이 없어지는지 확인합니다.
5. 삭제 확인 후 목록에서 사라지는지 확인합니다. 기본 수건은 예약 중이라 수정·삭제가 제한됩니다.
6. 마이페이지 → 회원정보 수정: 이름 변경 후 홈 인사말을 확인합니다.
7. 탐색에서 없는 검색어를 입력하고 초기화합니다. 지역과 카테고리를 함께 적용합니다.

초기 샘플로 돌아가려면 개발자 도구의 Application → Session Storage에서 이 사이트의 `issum-donor-demo-v1` 항목만 삭제한 뒤 새로고침합니다. 현재 탭의 데모 입력은 사라집니다.

## 검증 명령

```sh
pnpm lint
pnpm build
node --experimental-strip-types --test tests/*.test.mjs
```

브라우저 테스트는 별도 Playwright 설치가 있는 환경에서 `node tests/donor.e2e.mjs`로 실행합니다. 기본 대상은 `http://127.0.0.1:5173`입니다. `TEST_BASE_URL`로 주소, `PLAYWRIGHT_MODULE`로 설치된 Playwright 모듈 경로, `CHROME_PATH`로 Chrome 실행 파일을 지정할 수 있습니다. 독립 브라우저 컨텍스트를 사용하므로 기존 사용자 탭의 데이터를 변경하지 않습니다. 스크린샷은 Git에서 제외된 `test-artifacts/`에 생성됩니다.

## API 연동 시 남는 작업

- 로컬 저장소를 실제 조회·생성·수정·삭제·프로필 API로 교체하고 요청/응답 타입을 확정합니다.
- 이미지 업로드와 서버 이미지 URL, 인증된 사용자 ID를 연결합니다.
- 실제 추천 후보·기관 연락처·필요 물품 ID를 사용합니다. `sample-` ID를 서버로 전송하면 안 됩니다.
- 네트워크 로딩·재시도·서버 검증 오류·인증 만료·권한 오류·수량 경쟁 상태를 실제 응답과 함께 처리합니다.
- B 담당 인증·로그아웃·회원 탈퇴·매칭 생성·채팅·알림·완료 처리와 통합 검증합니다. 현재 인증 가드는 접근을 제한하지 않습니다.
- 부분 배분과 단일 수혜기관 정책의 최종 합의가 필요합니다. 현재 선택은 물품당 한 기관, 표시 수량은 예약을 뺀 잔량입니다. 실제 예약은 생성하지 않습니다.

이 데모는 실제 AI 추천이나 기관 신청·거래 완료를 실행하지 않습니다. 화면 기능 검증과 실제 서비스 통합 완료는 구분합니다.
